## Application checklist

Каждая application требует одинаковый набор документов (с вариациями):

- [ ] Pitch deck (15-20 slides)
- [ ] Executive summary (1 page)
- [ ] Financial projections (3-5 years)
- [ ] Cap table
- [ ] Team CVs / LinkedIn
- [ ] Reference implementation link (github.com/agisota/cpp-core)
- [ ] Public design document
- [ ] Customer pipeline (this doc, sanitized)
- [ ] Letters of Intent / pilot agreements (when available)
- [ ] Technical demo video (3-5 min)
- [ ] arXiv preprint (when ready)
- [ ] Legal: certificate of incorporation, share class structure

См. `strategy/deck-outline.md` и `strategy/pilot-contract-template.md`.
